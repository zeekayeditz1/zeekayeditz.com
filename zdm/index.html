INSTALL ONCE. THEN GET BACK TO EDITING.

Install ZDM and connect your browser.

There is no license-key activation. “Activation” here means connecting the browser companion to your local ZDM app.

  1. Download and install the Windows app

    Use the gold download button to open the Google Drive file, then choose Drive’s Download button. Run ZDM-Next-Setup-1.2.3.exe and open ZDM Next from your desktop or Start menu. If you are updating, first choose Exit ZDM from the existing tray icon.

  2. Check the required runtimes

    ZDM uses the .NET 10 Desktop Runtime for Windows x64 and Microsoft Edge WebView2 Runtime. If Windows reports either is missing, install it from Microsoft, then reopen ZDM.

  3. Open the paired extension folder

    In ZDM, select Browser integration → Open extension folder. The installed folder is normally C:\Users\USERNAME\AppData\Local\Zeekay\ZDMNext\Browser Extension. Replace USERNAME with your Windows account name. Use this app-generated folder: a source-code extension folder is not automatically paired.

  4. Load it in Chrome or Edge

    In Chrome, type chrome://extensions in the address bar. In Edge, type edge://extensions. Enable Developer mode, click Load unpacked, and select the Browser Extension folder opened by ZDM. Pin the extension and refresh video tabs that were already open.

  5. Choose your video or audio format

    Keep the desktop app running, play a supported video, and click the gold ZDM badge near its upper-right corner. Choose Video or Audio, select an available format, then Download. You can also use Add URL or Batch inside the desktop app.

  6. Make it yours

    Set a default folder and output preset in Settings. Choose narrow or wide progress mode once; future popups use your last choice. Enable Start with Windows if you want ZDM ready in the tray when you sign in.

Badge missing or not connected? Confirm ZDM is running, load the folder from that installation, refresh the video tab, and check the extension connection. Orange means analyzing, green means formats ready, and red means analysis failed. Try Refresh formats; use the extension popup if a site’s fullscreen player hides the badge. A scheduled queue needs ZDM to remain running.

ZDM 1.2.3

Specifications at a glance.

Desktop platform
Windows x64; Windows 11 recommended. Windows must support the required .NET 10 Desktop Runtime.
Browser companion
Google Chrome and Microsoft Edge; installed using Load unpacked.
Download engines
Native C# HTTP transfers for direct files; on-demand yt-dlp for supported websites and adaptive streams.
Media tools
FFmpeg for merging/conversion and FFprobe for stream checks; media tools are bundled with this installer.
Connection options
4 / 8 / 16 direct-file connections; up to 8 simultaneous downloads. Server support determines resumability and parallel transfer behavior.
Local browser bridge
Authenticated loopback connection on port 8990. The app must be running on the same Windows account.
Batch & scheduling
Up to 50 reviewed links per batch, queue priority and a scheduled start while the app is running.
Appearance & storage
Aurora/Charcoal themes, cards/list view, saved window geometry, remembered popup mode, favorites and per-download filenames.
Price & activation
Free gift from ZeeKay Editz. No paid activation key.

Supported sources can include YouTube and other website videos, direct files, HLS and DASH. Site availability changes. DRM/protected media, automatic browser-cookie transfer and universal website coverage are not offered. HDR sources are not automatically tone-mapped by the Editing preset; use a suitable SDR source or Original mode. Download only media you own or have permission to use.

QUICK ANSWERS

Before your first download.

Is ZDM free?

Yes. ZDM 1.2.3 is a free gift from ZeeKay Editz to the video editing community. No paid activation key is needed.

Does ZDM work with YouTube?

ZDM supports YouTube and other supported website videos. The formats and resolutions shown depend on the source and current site availability; every website or protected video is not supported.

Does the browser extension work on its own?

No. Keep the ZDM Windows app running. Load the Browser Extension folder generated by your installation so the extension can connect to its local desktop bridge.

Which format should I choose for an editing workflow?

The Editing preset targets H.264 video and AAC audio in MP4. Choose Original to keep the source format, AAC/M4A for compressed audio, or 48 kHz, 24-bit WAV for PCM audio. Compatibility still depends on your editor and source media.

Is there a Mac, mobile or Firefox version?

This release is a Windows x64 desktop app with Chrome and Edge extension setup. It does not include a native macOS, mobile or Firefox build.

What do the badge colors mean?

Orange means formats are being analyzed, green means choices are ready, and red means analysis failed. Try Refresh formats and check the desktop connection if needed.
